title: S3

---

## Для чего

Чтобы хранить файлы, бэкапы, статику и data lake без своего файлового сервера.

## Пример

Presigned URL для upload аватара. Статика сайта / артефакты CI. Lifecycle → Glacier.

## Примечание

Не файловая система и не БД для частых мелких мутаций. Публичный bucket без политики — классическая утечка. Версионирование спасает от overwrite.
