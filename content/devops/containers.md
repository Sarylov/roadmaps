title: Containers
summary: Container — запущенный экземпляр image: изолированный процесс с своей FS-view, сетью и лимитами, разделяющий ядро хоста.
---

## Для чего

Чтобы запускать сервисы изолированно и воспроизводимо, легче VM.

## Пример

`docker run -d -p 3000:3000 --name api api:1.2` — процесс слушает внутри, порт проброшен на хост.

## Примечание

Контейнер ≠ мини-ВМ: нет своего ядра. Эфемерен: данные вне volumes пропадут. Один контейнер — обычно один главный процесс.
