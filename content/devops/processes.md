---

## Для чего

Чтобы понимать, кто ест CPU/память, как убить зависшее и чем wrapper/systemd отличается от «просто node app.js».

## Пример

`ps`, `top`/`htop` — список. `kill -TERM <pid>` — мягкая остановка. Node cluster/PM2 — несколько worker-процессов.

## Примечание

Зомби/orphan, лимиты `ulimit`, exit code для оркестраторов. Контейнер обычно = один главный процесс (PID 1) — важен signal handling.
