---
title: Networks
summary: Docker network — виртуальная сеть между контейнерами: DNS по имени сервиса, изоляция от других сетей.
---

## Для чего

Чтобы `api` ходил на `postgres:5432` по имени, а лишние контейнеры не торчали в ту же сеть без нужды.

## Пример

Compose создаёт сеть проекта: сервис `db`, из `api` — `DATABASE_URL=postgres://db:5432/...`.

## Примечание

Bridge — дефолт для single-host. Не публикуйте порты БД наружу без причины. `host` network — без изоляции портов Docker.
