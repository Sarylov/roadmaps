---
title: Arrays
summary: Arrays — встроенный тип массива в PostgreSQL (`text[]`, `int[]`): значение — список элементов одной колонки.
---

## Для чего

Чтобы хранить небольшой упорядоченный набор без отдельной таблицы связей, когда набор — атрибут сущности.

## Пример

```sql
tags text[] DEFAULT '{}';
WHERE 'urgent' = ANY(tags);
```

## Примечание

Плохо масштабируется как «много-ко-многим большого графа» — там junction table. Индексация: GIN на массив.
