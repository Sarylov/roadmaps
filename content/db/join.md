---
title: JOIN
summary: JOIN — соединение строк из нескольких таблиц по условию связи (обычно ключам).
---

## Для чего

Чтобы собрать связанные данные (заказ + пользователь) одним запросом вместо N+1 в приложении.

## Пример

```sql
SELECT o.id, u.email
FROM orders o
JOIN users u ON u.id = o.user_id;
```

## Примечание

`INNER` / `LEFT` / `RIGHT` меняют, какие «сироты» останутся. Неверный JOIN размножает строки. Индексы на join-ключах критичны.
