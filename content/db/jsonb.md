---
title: JSONB
summary: JSONB — бинарный JSON-тип PostgreSQL: хранит документ, индексируется (GIN), запрашивается операторами `->` / `@>`.
---

## Для чего

Чтобы гибкие/редкие поля не плодить сотни nullable-колонок, сохраняя запросы и индексы по ключам.

## Пример

```sql
SELECT payload->>'status' FROM events WHERE payload @> '{"type":"signup"}';
CREATE INDEX ON events USING GIN (payload);
```

## Примечание

Не замена нормальной модели для ядра домена. Частые фильтры по ключу JSONB всё равно стоит индексировать точечно / выносить в колонку.
