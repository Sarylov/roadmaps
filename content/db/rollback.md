---
title: Rollback
summary: Rollback — отмена транзакции: все её изменения отбрасываются, как будто их не было.
---

## Для чего

Чтобы безопасно выйти из частичного сбоя (ошибка, deadlock, бизнес-отказ) без полуприменённого состояния.

## Пример

```sql
BEGIN;
UPDATE accounts SET bal = bal - 100 WHERE id = 1;
-- ошибка / проверка не прошла
ROLLBACK;
```

## Примечание

Rollback не «чинит» уже сделанный commit. Вложенные savepoint позволяют откатить кусок, не всю tx.
