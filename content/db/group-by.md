---
title: GROUP BY
summary: GROUP BY — свёртка строк в группы с агрегатами (COUNT, SUM, AVG…).
---

## Для чего

Чтобы считать метрики по срезам: заказы по дням, сумма по пользователю.

## Пример

```sql
SELECT user_id, COUNT(*) 
FROM orders 
GROUP BY user_id;
```

## Примечание

В SELECT можно брать только ключи группировки и агрегаты (в Postgres строго). «Лишняя» колонка без агрегата — ошибка.
