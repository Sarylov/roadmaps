---
title: Composite indexes
summary: Composite index — индекс по нескольким колонкам в фиксированном порядке (a, b, c).
---

## Для чего

Чтобы закрыть частый фильтр/сортировку сразу по нескольким полям одним индексом.

## Пример

```sql
CREATE INDEX ON orders (user_id, created_at);
-- хорошо: WHERE user_id = 1 ORDER BY created_at
-- слабо: WHERE created_at > ... без user_id (левый префикс)
```

## Примечание

Порядок колонок критичен: работает левый префикс. Индекс `(a,b)` не заменяет отдельный частый поиск только по `b`.
