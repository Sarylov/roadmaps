---
title: SELECT
summary: SELECT — запрос на чтение строк и столбцов из таблицы (или выражения).
---

## Для чего

Чтобы достать нужные данные из БД, не таща лишние колонки и строки.

## Пример

```sql
SELECT id, email FROM users WHERE active = true;
```

## Примечание

`SELECT *` в проде обычно плох: лишний I/O и хрупкость при добавлении колонок. Список полей помогает covering indexes.
