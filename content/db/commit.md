---
title: Commit
summary: Commit — фиксация транзакции: изменения становятся видимы другим и долговечны (в рамках durability СУБД).
---

## Для чего

Чтобы атомарно «опубликовать» набор изменений после успешной бизнес-операции.

## Пример

```sql
BEGIN;
UPDATE ...;
INSERT ...;
COMMIT;
```

## Примечание

После commit откатить «как rollback» нельзя — нужен compensating action. Пока нет commit, другие (в RC) не видят ваши dirty writes.
