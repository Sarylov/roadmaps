---
title: Navigation
summary: Navigation — смена маршрута: `<Link>`, `useNavigate`, редиректы; без полной перезагрузки документа в SPA.
---

## Для чего

Чтобы переходы были быстрыми и сохраняли client state там, где нужно.

## Пример

`<Link to={`/users/${id}`}>` — доступная навигация.  
`navigate('..', { replace: true })` после submit.

## Примечание

Для внешних URL — обычный `<a>`. Prefetch ссылок ускоряет UX; не злоупотребляйте на мобильном трафике.
