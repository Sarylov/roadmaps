---
title: Custom hooks
summary: Custom hook — функция `use…`, которая вызывает другие хуки и выносит переиспользуемую логику состояния/эффектов.
---

## Для чего

Чтобы не копипастить useState/useEffect между компонентами и тестировать логику отдельно от JSX.

## Пример

`function useToggle(init=false) { const [on, set] = useState(init); return [on, () => set(v => !v)] }`

## Примечание

Правила хуков те же: только сверху, только из React-функций/хуков. Имя с `use` нужно линтеру правил.
