---
title: Keys
summary: Keys — стабильные идентификаторы элементов в списке для reconciliation: понять, что сдвинулось/удалилось.
---

## Для чего

Чтобы корректно сохранять state строк списка при сортировке/вставках и не путать DOM-узлы.

## Пример

`items.map(i => <Row key={i.id} …})` — хорошо.  
`key={index}` — плохо, если список переупорядочивается.

## Примечание

Key только среди siblings. Не используйте Math.random() — будет полный remount каждый раз.
