---
title: Hydration mismatch
summary: Hydration mismatch — HTML с сервера не совпал с тем, что клиентский React ожидает при гидратации.
---

## Для чего

Чтобы чинить белые экраны/варнинги и битую интерактивность после SSR.

## Пример

Сервер: `Date.now()` / `Math.random()` / `window` в render → другая разметка на клиенте. Лечение: одинаковый вывод или `useEffect` только на клиенте.

## Примечание

Проверяйте локаль/timezone, `typeof window`, расширения браузера, лишний whitespace. В React 19/современном стеке сообщения об ошибке явнее.
