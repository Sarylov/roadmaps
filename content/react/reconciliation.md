---
title: Reconciliation в React
summary: Reconciliation — алгоритм, которым React сопоставляет прошлое и новое дерево элементов и решает, какие части DOM сохранить, обновить или пересоздать.
---

## Зачем нужно

Без понимания reconciliation сложно объяснить роль `key`, причины потери локального состояния и то, почему «ререндер компонента» не равен изменению DOM.

## Как работает

После обновления React вызывает компоненты и получает новое дерево элементов. Во время render phase он сравнивает его с предыдущим деревом Fiber. Элементы разных типов считаются разными поддеревьями: старое демонтируется, новое создаётся. Для одинакового типа React сохраняет экземпляр и состояние, обновляет props и рекурсивно сравнивает детей.

Списки сопоставляются по `key` и типу. Без стабильного `key` React ориентируется на позицию, поэтому вставка или сортировка может привязать состояние к другой строке. Результат сравнения применяется к DOM в commit phase. Эвристика работает примерно за O(n), а не ищет минимальный diff произвольных деревьев.

## Что спрашивают

- Чем ререндер отличается от изменения DOM?
- Когда React сохраняет состояние компонента, а когда сбрасывает?
- Почему reconciliation не вычисляет математически минимальный diff?

## Ответы

### Чем ререндер отличается от изменения DOM?

Ререндер — повторный вызов компонента для построения элементов. Reconciliation может определить, что DOM менять не нужно. Даже при изменениях React применяет только рассчитанные операции в commit phase.

### Когда React сохраняет состояние компонента, а когда сбрасывает?

Состояние связано с позицией Fiber в дереве. Оно сохраняется при совпадении типа и `key`; смена типа, `key` или позиции без корректных ключей приводит к размонтированию и новому состоянию.

### Почему reconciliation не вычисляет математически минимальный diff?

Точный tree diff слишком дорог для UI. React использует практические допущения: разные типы дают разные поддеревья, а разработчик сообщает идентичность элементов через `key`. Это обеспечивает предсказуемую линейную эвристику.
