## Для чего

Чтобы меньше JS на клиенте: контент статичен, гидратим корзину/поиск, не всю страницу.

## Пример

Astro/частично Next: статья — HTML; компонент комментариев — island с своим JS.

## Примечание

Связь островов — через события/URL/сервер, не один большой client store по умолчанию.
