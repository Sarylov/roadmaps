---
title: Virtualization
summary: Virtualization (windowing) — рендер только видимых строк списка + небольшой overscan, а не всех 10k DOM-узлов.
---

## Для чего

Чтобы длинные списки оставались плавными по памяти и FPS.

## Пример

`react-window` / TanStack Virtual: в viewport 20 строк из 50 000; при скролле переиспользуются ячейки.

## Примечание

Нужны оценка высоты/измерение. SEO для виртуализированного контента — отдельный вопрос (часто ок для app UI).
