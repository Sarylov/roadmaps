---

## Для чего

Чтобы один и тот же образ/артефакт работал в dev/stage/prod без пересборки под каждый стенд.

## Пример

```js
const port = Number(process.env.PORT ?? 3000)
const dbUrl = process.env.DATABASE_URL // обязателен — валидируют на старте
```

## Примечание

Секреты не в git и не в образ «навечно». На старте проверяйте env схемой (zod и т.п.), иначе падение в рантайме на первом запросе.
