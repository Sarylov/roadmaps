## Зачем нужно

Чтобы явно выразить и переиспользовать поведение, связанное с «threads», а не держать его зашитым в одном месте.

## Как работает

Web Worker — это фоновый поток без DOM.

Частая ошибка: обмен postMessage/structured clone (или transferable).

Документация: [Node.js](https://nodejs.org/docs/latest/api/).

## Ответы

### Что такое threads простыми словами?

Web Worker — это фоновый поток без DOM.

### Зачем в коде нужен threads?

Чтобы явно выразить и переиспользовать поведение, связанное с «threads», а не держать его зашитым в одном месте.

### Какие ошибки и ограничения связаны с threads?

Обмен postMessage/structured clone (или transferable). Имеет смысл сравнить с ближайшей альтернативой и понять, когда механизм избыточен.
