---
title: libuv
summary: libuv — C-библиотека под Node: event loop, неблокирующий сетевой I/O и thread pool для части операций.
---

## Для чего

Чтобы объяснить, кто на самом деле ждёт сокеты и файлы, пока JS-код не крутится в ожидании.

## Пример

`fs.readFile` часто уходит в thread pool libuv; сеть обычно через epoll/kqueue/IOCP без потока на каждый сокет. Готовность → колбэк в JS.

## Примечание

Размер пула: `UV_THREADPOOL_SIZE` (по умолчанию невелик). Забитый пул = «медленный fs/dns/crypto», хотя event loop «свободен».
