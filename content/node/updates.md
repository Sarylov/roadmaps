## Зачем нужно

Чтобы явно выразить и переиспользовать поведение, связанное с «updates», а не держать его зашитым в одном месте.

## Как работает

updates — это обновление SW: install → waiting → activate.

Частая ошибка: застрявший waiting SW путает пользователей.

Документация: [Node.js](https://nodejs.org/docs/latest/api/).

## Ответы

### Что такое updates простыми словами?

updates — это обновление SW: install → waiting → activate.

### Зачем в коде нужен updates?

Чтобы явно выразить и переиспользовать поведение, связанное с «updates», а не держать его зашитым в одном месте.
