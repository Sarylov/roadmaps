---
title: Unit tests
summary: Unit test — проверка небольшой единицы (функция, хук, чистый компонент) в изоляции от сети и тяжёлого DOM-окружения.
---

## Для чего

Чтобы быстро ловить регрессии логики без поднятия всего приложения.

## Пример

`expect(formatPrice(1500)).toBe('1 500 ₽')`.  
Хук `useToggle` — renderHook + act. Компонент кнопки — RTL без MSW, если нет fetch.

## Примечание

Мокайте границы (API, time), не всю внутренность. Слишком много unit без integration не ловит wiring.
