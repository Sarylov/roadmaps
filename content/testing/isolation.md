---
title: Isolation
summary: Test isolation — тесты не зависят друг от друга: порядок, shared state и побочные эффекты не влияют на результат.
---

## Для чего

Чтобы suite был детерминированным в parallel CI и при запуске одного файла.

## Пример

Каждый тест — свой user id / rollback транзакции / отдельная schema. Нет «тест B ждёт, что A что-то создал».

## Примечание

Глобальные singletons, общий Redis без ключей-префиксов и неснятые моки — частые враги изоляции.
