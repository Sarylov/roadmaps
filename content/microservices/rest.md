---
title: REST
summary: REST в микросервисах — синхронное HTTP API вокруг ресурсов (JSON), привычный request/response между сервисами и клиентами.
---

## Для чего

Чтобы просто и явно вызывать чужой use-case и сразу получить результат/ошибку.

## Пример

`POST /orders` → `201`. Inventory: `GET /stock/{sku}`. Клиент ждёт ответа в том же соединении.

## Примечание

Сильная связность по времени: если Inventory лежит — Orders тоже страдает без resilience. Для fan-out и пиков часто дополняют сообщениями.
