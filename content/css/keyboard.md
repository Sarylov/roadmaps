title: Keyboard
summary: Keyboard accessibility — интерфейс полностью управляем с клавиатуры: Tab, Enter/Space, стрелки, Escape.
---

## Для чего

Чтобы пользователи без мыши (и многие power users) могли пользоваться сайтом.

## Пример

Tab по фокусируемым контролам; Enter активирует кнопку; Escape закрывает модалку; ловушка фокуса в диалоге.

## Примечание

Кастомный `div` с onClick без `tabIndex` и key handlers — ловушка. Предпочитайте `<button>`/`<a href>`.

## Вопросы и ответы

### Что должно быть в tab order?

Интерактив: ссылки, кнопки, поля, custom widgets с tabindex=0. Декор — нет.

### Зачем focus trap в модалке?

Чтобы Tab не уводил фокус «под» оверлей на страницу сзади.
