---
title: Flex
summary: Flexbox — одномерная раскладка: элементы в ряд или колонку с распределением пространства и выравниванием.
---

## Для чего

Чтобы быстро выстраивать навбар, карточки в ряд, центрирование и «прижать футер» без float-хаков.

## Пример

```css
.row { display: flex; gap: 1rem; align-items: center; justify-content: space-between; }
```

## Примечание

Главная ось — `flex-direction`. `flex: 1` растягивает. Для двумерных сеток чаще Grid.

## Вопросы и ответы

### Когда flex, когда grid?

Flex — один ряд/колонка и выравнивание вдоль оси. Grid — строки и колонки сразу.

### Что делают align-items и justify-content?

`justify-content` — по главной оси, `align-items` — по поперечной.
