---
title: Opacity
summary: Opacity — прозрачность всего элемента вместе с детьми (0…1); влияет на stacking context при значении < 1.
---

## Для чего

Чтобы делать fade-анимации и полупрозрачные оверлеи.

## Пример

`opacity: 0` + `pointer-events: none` — скрыть визуально для анимации.  
Для прозрачного фона без детей — `background: rgba(...)` / `#0008`.

## Примечание

`opacity` на родителе «приглушает» и текст детей; нельзя вернуть ребёнку opacity 1 «выше» родителя. Создаёт stacking context если < 1.

## Вопросы и ответы

### Чем opacity отличается от rgba фона?

opacity на всём элементе включая контент; rgba — только на том свойстве (например фоне).

### Почему opacity в анимациях любят вместе с transform?

Оба хорошо композитятся, меньше layout/paint стоимости, чем анимация размеров.
