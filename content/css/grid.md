---
title: Grid
summary: CSS Grid — двумерная раскладка по строкам и колонкам с явными треками и областями.
---

## Для чего

Чтобы собирать страничные сетки, галереи и сложные макеты без вложенных flex-обёрток.

## Пример

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}
```

## Примечание

`fr` делит свободное место. `grid-template-areas` удобен для именованных зон. Subgrid — когда дочерняя сетка должна совпасть с родительской.

## Вопросы и ответы

### Чем grid отличается от flex?

Grid двумерен (ряды+колонки), flex — в основном одна ось. Часто комбинируют: grid страница, flex внутри карточки.

### Что такое 1fr?

Доля свободного пространства в треке после фиксированных размеров.
