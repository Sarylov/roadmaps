---
title: Reduced motion
summary: prefers-reduced-motion — media query: пользователь просит меньше анимаций (вестибулярные/нейропричины).
---

## Для чего

Чтобы не навязывать motion и уважать системную настройку OS/браузера.

## Пример

```css
@media (prefers-reduced-motion: reduce) {
  * { animation: none; transition: none; }
}
```
Или укоротить/упростить, не обязательно вырезать всё.

## Примечание

Критичные недекоративные переходы можно оставить мягкими. Проверяйте в OS «уменьшить движение».

## Вопросы и ответы

### Обязательно ли отключать все анимации?

Не всегда: уберите параллакс/кружение; лёгкий fade часто ок. Главное — не игнорировать настройку.

### Как проверить?

DevTools → emulate prefers-reduced-motion или системные настройки accessibility.
