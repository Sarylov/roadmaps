## Для чего

Чтобы выбирать инструмент раскладки под задачу и понимать, как браузер считает геометрию.

## Пример

Документ в normal flow → секции grid → навбар flex → бейдж `position: absolute` внутри карточки.

## Примечание

Сначала структура и поток, потом исключения (absolute/fixed). Не решайте всё через `position`.

## Вопросы и ответы

### Что такое normal flow?

Обычное следование блочных элементов сверху вниз и inline — в строке, без flex/grid/absolute.

### Почему float почти не используют для сеток?

Хрупкий clearfix, плохая доступность паттернов. Flex/grid закрывают те же задачи чище.
