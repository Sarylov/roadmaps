## Как работает

**ARIA**: ARIA дополняет семантику, когда HTML не выражает роль/состояние.

ARIA на «битых» интерактивах без клавиатуры хуже, чем нативный контроль.

Первое правило ARIA: не используй ARIA, если есть нативный HTML.
