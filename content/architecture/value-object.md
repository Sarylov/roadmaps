## Зачем нужно

Тема регулярно встречается на backend-интервью: сильный ответ связывает механизм с наблюдаемым поведением, отказами и production-решением.

## Как работает

`Money(amount, currency)` запрещает отрицательное значение при необходимости и складывается только с той же валютой, возвращая новый объект. После успешного конструктора остальной домен может считать инвариант выполненным.

## Ответы

### Как работает Value Object на практике?

`Money(amount, currency)` запрещает отрицательное значение при необходимости и складывается только с той же валютой, возвращая новый объект. После успешного конструктора остальной домен может считать инвариант выполненным.

### Какой типичный failure mode связан с Value Object?

Primitive obsession смешивает `userId`, `email` и обычные строки, размазывая validation. Mutable value object, используемый как ключ Map или часть entity, меняется незаметно и ломает equality.

### Какие trade-offs важно назвать для Value Object?

Value object полезен для повторяемого правила и поведения. Для локального поля без инвариантов отдельный класс может быть шумом; serialization и ORM mapping проектируют явно.
