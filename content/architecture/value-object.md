---
title: Value Object
summary: Value Object — объект без собственной идентичности: определяется значениями; неизменяем и сравнивается по полям.
---

## Для чего

Чтобы выразить деньги, email, диапазон дат типом с правилами, а не «голыми» string/number.

## Пример

`Money(100, 'USD')` равен другому `Money(100, 'USD')`. Сложение валют проверяет совпадение currency.

## Примечание

Иммутабельность упрощает рассуждения. Не путать с entity: у VO нет «своего» id в таблице смысла идентичности.
