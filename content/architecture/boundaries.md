title: Boundaries
summary: Boundaries — явные границы модулей/слоёв: что можно вызвать снаружи, какие DTO пересекают черту.
---

## Для чего

Чтобы изменения в одной зоне (платежи) не расползались по всему монолиту.

## Пример

Модуль `billing` экспортирует `createInvoice()`, но не таблицы ORM. Другие зоны ходят только в публичный API модуля.

## Примечание

Граница без enforcement (lint/модули/package) быстро стирается. На собесе — про coupling и контракты, не про названия папок.
