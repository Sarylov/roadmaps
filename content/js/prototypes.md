## Для чего

Чтобы делить методы между экземплярами без копирования функции в каждый объект.

## Пример

```js
const animal = { eat() { return 'nom' } }
const dog = Object.create(animal)
dog.bark = () => 'woof'
dog.eat() // находит метод в прототипе animal
```

## Примечание

У функции-конструктора есть `.prototype` (что получат инстансы). У объекта — `[[Prototype]]` (`Object.getPrototypeOf`). `class` — сахар над этой же моделью.

## Вопросы и ответы

### Как работает поиск свойства по прототипу?

Сначала смотрят сам объект. Если свойства нет — идут по `[[Prototype]]` вверх по цепочке, пока не найдут или не дойдут до `null`.

### Чем `__proto__` / `[[Prototype]]` отличается от `Fn.prototype`?

`Fn.prototype` — объект, который станет `[[Prototype]]` у инстансов `new Fn()`. У конкретного объекта цепочка — это `Object.getPrototypeOf(obj)` (исторически ещё `__proto__`).

### Зачем прототипы, если есть `class`?

`class` — синтаксический сахар над той же моделью: методы всё равно на `.prototype`, наследование — через цепочку прототипов.
