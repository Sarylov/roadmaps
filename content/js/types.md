## Для чего

Чтобы понимать, что лежит в переменной, какие операции допустимы и где язык сам приводит типы.

## Пример

```js
typeof 1          // "number"
typeof null       // "object"  — исторический баг
typeof []         // "object"
```

## Примечание

Примитивы копируются по значению, объекты — по ссылке. `typeof null === "object"` — исключение, которое нужно помнить.

## Вопросы и ответы

### Какие типы есть в JavaScript?

Примитивы: `number`, `string`, `boolean`, `null`, `undefined`, `symbol`, `bigint`. Всё остальное — `object` (включая массивы и функции).

### Почему `typeof null` возвращает `"object"`?

Исторический баг языка: в первых реализациях `null` был помечен как object-type. Сейчас это зафиксировано в спецификации — так и оставляют ради совместимости.

### Чем отличается копирование примитивов и объектов?

Примитив копируется по значению: изменили копию — оригинал не тронут. Объект передаётся по ссылке: две переменные указывают на один и тот же объект в памяти.
