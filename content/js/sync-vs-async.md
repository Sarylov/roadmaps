title: Sync vs async
summary: Sync — код ждёт завершения операции сейчас; async — запускает работу и продолжает, результат приходит позже (callback/Promise).
---

## Для чего

Чтобы не блокировать event loop на I/O и понимать, где нужна последовательность, а где параллельность.

## Пример

Sync: `fs.readFileSync` — пока читает файл, ничего другого.  
Async: `await fetch(url)` — пока ждём сеть, Node обрабатывает другие события.

## Примечание

`async` функция всё равно выполняется синхронно до первого `await`. Между сервисами «sync» часто = HTTP request/response, «async» = очередь/событие.

## Вопросы и ответы

### Чем sync отличается от async в Node?

Sync блокирует поток до конца операции. Async регистрирует работу и возвращает управление event loop, результат — позже через Promise/callback.

### Почему на I/O предпочитают async?

Чтобы один процесс обслуживал много соединений, не простаивая на каждом диске/сети.
