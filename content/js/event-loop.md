---
title: Event loop
summary: Event loop — цикл, который берёт задачи из очередей и выполняет их, когда call stack пуст.
---

## Для чего

Чтобы один поток JS мог обслуживать много асинхронных операций: таймеры, сеть, промисы — без отдельного потока на каждый запрос.

## Пример

1. Выполнили синхронный код (stack).  
2. Опустошили microtasks.  
3. Взяли одну macrotask (например `setTimeout`).  
4. Снова microtasks → дальше по кругу.

## Примечание

В браузере между macrotasks может быть render. В Node — фазы libuv (`timers`, `poll`, `check`…). Модели похожи по идее, детали отличаются.

## Вопросы и ответы

### Что делает event loop?

Когда call stack пуст, берёт задачи из очередей и выполняет их: так один поток обслуживает таймеры, сеть и промисы без отдельного потока на каждый запрос.

### Какой типичный порядок на одном «круге»?

Синхронный код (stack) → опустошить microtasks → взять одну macrotask → снова microtasks → и по кругу. В браузере между macrotasks может вклиниться render.

### Одинаков ли loop в браузере и Node?

Идея одна, детали разные: в Node фазы libuv (`timers`, `poll`, `check`…). Для собеса важнее общий порядок sync → micro → macro.
