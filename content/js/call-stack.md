## Для чего

Чтобы понимать порядок выполнения и почему долгий синхронный код блокирует всё остальное.

## Пример

```js
function a() { b() }
function b() { c() }
function c() { throw new Error('boom') }
a()
// stack: a → b → c
```

## Примечание

Пока стек не пуст, event loop не берёт следующую задачу. Бесконечная рекурсия → stack overflow.

## Вопросы и ответы

### Что такое call stack?

Стек кадров текущих синхронных вызовов: кто кого вызвал и что выполняется прямо сейчас. `return` снимает кадр сверху.

### Почему долгий синхронный код «вешает» приложение?

Пока стек не пуст, event loop не берёт следующую задачу — таймеры, I/O-колбэки и промисы ждут.

### Откуда берётся stack overflow?

Слишком глубокая рекурсия (или взаимные вызовы) без выхода: кадры копятся, пока не упрётесь в лимит → `RangeError: Maximum call stack size exceeded`.
