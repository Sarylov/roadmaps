## Ответы

### Что такое memory leaks и как его распознать в системе?

Утечки в Node: глобальные кэши, слушатели, uncleared timers. Симптомы обычно видны в логах, метриках latency/error rate или профилировщике. Назовите конкретный сигнал для «Memory & GC».

### Как диагностировать и устранить memory leaks?

clinic/heap snapshots. Алгоритм ответа: воспроизвести → найти причину на границе (данные/сеть/лок/запрос) → фикс + регрессионный тест. Ограничивайте размер кэшей (LRU).

### Как предотвратить memory leaks в архитектуре и процессе?

Профилактика сильнее тушения: лимиты, таймауты, идемпотентность, индексы/батчинг, code review чеклист. Для «Memory & GC» зафиксируйте NFR и алерты на ранние симптомы.
