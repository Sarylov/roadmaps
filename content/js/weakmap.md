---
title: WeakMap
summary: WeakMap — Map, где ключи-объекты удерживаются слабо: не мешают GC ключа.
---

## Для чего

Чтобы вешать метаданные на объекты без утечки, когда сам объект уже никому не нужен.

## Пример

```js
const meta = new WeakMap()
meta.set(user, { cachedAt: Date.now() })
// когда user больше нигде не ссылается — запись может исчезнуть вместе с ним
```

## Примечание

Ключи только объекты (не примитивы). WeakMap не итерируется и не знает свой размер — это следствие слабых ссылок.

## Вопросы и ответы

### Чем WeakMap отличается от Map?

Ключи-объекты удерживаются слабо: если на объект больше нет сильных ссылок, запись может исчезнуть вместе с ним и не мешает GC.

### Зачем WeakMap на практике?

Метаданные на объектах (кэш при объекте, private-like данные) без утечки: когда объект больше никому не нужен, запись не удерживает его в памяти.

### Почему у WeakMap нет `.size` и итерации?

Слабые ссылки недетерминированны: размер и обход были бы ненадёжны. Ключи — только объекты, не примитивы.
