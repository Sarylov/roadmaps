title: Heap
summary: Heap — область памяти для объектов и замыканий; ими управляет garbage collector.
---

## Для чего

Чтобы понимать, где живут данные между запросами и почему растёт RSS процесса Node.

## Пример

```js
const cache = new Map()
cache.set(id, bigObject) // объект в heap, пока на него есть ссылка
```

## Примечание

Рост heap + частые GC pauses бьют по latency. Смотрят snapshots / clinic, а не только `process.memoryUsage()` разово.

## Вопросы и ответы

### Что хранится в heap?

Объекты, замыкания, структуры вроде `Map`/`Array` — всё, чем управляет garbage collector. Пока есть ссылка, объект живёт в heap.

### Почему рост heap бьёт по latency?

Больше объектов → чаще/дольше GC pauses. Процесс Node раздувает RSS; смотрят heap snapshots, а не один замер `memoryUsage()`.

### Чем heap отличается от stack в двух словах?

Stack — кадры вызовов и локальные примитивы текущего выполнения. Heap — долгоживущие объекты между вызовами и запросами.
