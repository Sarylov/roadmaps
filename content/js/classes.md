## Для чего

Чтобы описывать типы сущностей привычнее, чем вручную писать `function` + `Prototype`, сохраняя ту же прототипную модель.

## Пример

```js
class User {
  constructor(name) { this.name = name }
  hello() { return `hi, ${this.name}` }
}
new User('Ann').hello() // "hi, Ann"
```

## Примечание

Методы лежат на `User.prototype`, поля экземпляра — на самом объекте. Класс нельзя вызвать без `new`. `#field` — настоящая приватность.

## Вопросы и ответы

### Где живут методы класса и поля экземпляра?

Методы — на `ClassName.prototype` (общие для всех инстансов). Поля, заданные в `constructor` через `this`, — на самом объекте.

### Можно ли вызвать класс как обычную функцию?

Нет: без `new` будет `TypeError`. Это отличие от старых конструкторов-функций, которые иногда «прощали» вызов без `new`.

### Чем `#field` отличается от `_field` по соглашению?

`#field` — настоящая приватность языка: снаружи недоступно. `_field` — только договорённость; любой код может прочитать и изменить.
