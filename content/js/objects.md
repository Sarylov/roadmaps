title: Objects
summary: Object — структура «ключ → значение»; почти всё не-примитивное в JS — объект или ведёт себя как объект.
---

## Для чего

Чтобы группировать данные и методы в одну сущность и передавать их по ссылке.

## Пример

```js
const user = { id: 1, name: 'Ann' }
const same = user
same.name = 'Bob'
user.name // "Bob" — одна ссылка
```

## Примечание

Сравнение `===` для объектов — по ссылке, не по содержимому. Копия: `{ ...obj }` / `structuredClone`, а не `=`.

## Вопросы и ответы

### Как сравниваются объекты через `===`?

По ссылке: два литерала `{ a: 1 } === { a: 1 }` — `false`, даже при одинаковом содержимом. `true` только если обе переменные указывают на один и тот же объект в памяти.

### Чем `const obj = other` отличается от копии?

Присваивание копирует ссылку, не данные: правка через одну переменную видна в другой. Для копии нужны `{ ...obj }`, `Object.assign` или `structuredClone` для глубокой.

### Что значит «почти всё — объект»?

Массивы, функции, даты — это объекты (или обёртки). Примитивы — нет, но при доступе к методам (`'hi'.toUpperCase()`) временно ведут себя как объекты.
