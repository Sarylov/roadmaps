title: Scope
summary: Scope — область видимости: где имя переменной видно и доступно.
---

## Для чего

Чтобы не пересекать имена, скрывать внутренности функции и понимать, какую переменную читает код.

## Пример

```js
const x = 1
function f() {
  const x = 2
  console.log(x) // 2 — локальный scope
}
f()
console.log(x) // 1 — внешний
```

## Примечание

`let`/`const` — block scope; `var` — function scope. Lexical scope: видимость определяется местом в коде, а не местом вызова.

## Вопросы и ответы

### Чем отличаются `var`, `let` и `const` по области видимости?

`var` живёт в function scope (или глобально) и всплывает. `let`/`const` — block scope: видны только внутри `{ }`, где объявлены. `const` нельзя переназначить, но объект по ссылке менять можно.

### Что такое lexical scope?

Видимость имени задаётся местом объявления в коде, а не тем, откуда функцию вызвали. Вложенная функция видит внешние переменные по цепочке scopes вверх.

### Что будет, если обратиться к `let` до объявления в том же блоке?

Ошибка `ReferenceError` (Temporal Dead Zone): переменная уже «существует» в блоке, но ещё недоступна до строки с `let`/`const`.
