title: Closures
summary: Closure — функция, которая «помнит» переменные внешней области даже после того, как внешняя функция уже завершилась.
---

## Для чего

Чтобы хранить приватное состояние и передавать поведение наружу без глобальных переменных.

## Пример

```js
function makeCounter() {
  let n = 0
  return () => ++n
}
const c = makeCounter()
c() // 1
c() // 2
```

## Примечание

В цикле с `var` все колбэки делят одну переменную; с `let` — у каждой итерации своя. Долгоживущее замыкание может удерживать в памяти лишние данные.

## Вопросы и ответы

### Что такое closure?

Функция, которая сохраняет доступ к переменным внешней области даже после того, как внешняя функция уже вернула управление. Классика — счётчик или приватное состояние через возвращённую функцию.

### Почему в цикле с `var` все колбэки видят одно значение?

`var` одна на всю функцию: все замыкания ссылаются на ту же переменную. К моменту вызова она уже финальная. С `let` у каждой итерации свой binding.

### Может ли замыкание вызвать утечку памяти?

Да: пока жива внутренняя функция, живы и захваченные переменные. Если замыкание долгое (кэш, слушатель), оно может удерживать большие объекты дольше нужного.
