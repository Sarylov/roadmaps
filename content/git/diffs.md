## Зачем нужно

Чтобы явно выразить и переиспользовать поведение, связанное с «diffs», а не держать его зашитым в одном месте.

## Как работает

diffs — это code review читает diff на риски и ясность.

Частая ошибка: нитрайп по стилю, если есть форматтер.

## Что спрашивают

- Что такое diffs простыми словами?
- Зачем в коде нужен diffs?
- Какие ошибки и ограничения связаны с diffs?

## Ответы

### Что такое diffs простыми словами?

diffs — это code review читает diff на риски и ясность.

### Зачем в коде нужен diffs?

Чтобы явно выразить и переиспользовать поведение, связанное с «diffs», а не держать его зашитым в одном месте.

### Какие ошибки и ограничения связаны с diffs?

Нитрайп по стилю, если есть форматтер. Имеет смысл сравнить с ближайшей альтернативой и понять, когда механизм избыточен.
