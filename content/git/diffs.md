---

## Для чего

Чтобы ловить регрессии, лишний scope и риски до merge.

## Пример

Смотрите: API контракт, a11y, bundle impact, тесты на новый путь. Спрашивайте «почему так», если неочевидно.

## Примечание

Большой PR без описания — красный флаг. Ревьюер отвечает за понятность риска, не за nitpick пробелов (это Prettier).
