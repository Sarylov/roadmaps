---
title: Bisect
summary: git bisect — бинарный поиск коммита, который внёс баг: помечаете good/bad, Git прыгает по истории.
---

## Для чего

Чтобы быстро найти регрессию среди сотен коммитов, а не листать вручную.

## Пример

`git bisect start` → `bad` на HEAD → `good` на теге релиза → на каждом шаге тест → `git bisect reset`.

## Примечание

Нужен воспроизводимый тест (скрипт/`bisect run`). Работает лучше на линейной истории.
