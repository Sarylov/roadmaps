---
title: BFF
summary: BFF (Backend for Frontend) — backend-слой под конкретный клиент (web/mobile), адаптирует и агрегирует API под UI.
---

## Для чего

Чтобы мобилка и веб не жили на одном неудобном «общем» API и не тащили лишние поля/чаттеринг.

## Пример

`mobile-bff` отдаёт урезанные DTO и меньше round-trips; `web-bff` — богаче фильтры. Оба ходят во внутренние сервисы.

## Примечание

BFF — не свалка всей бизнес-логики домена. Дублирование между BFF контролируйте; общий domain остаётся в сервисах.
