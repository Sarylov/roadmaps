---
title: QUIC
summary: QUIC — транспорт на UDP под HTTP/3: быстрый handshake, мультиплекс без TCP head-of-line blocking.
---

## Для чего

Чтобы ускорить установку соединения и переживать потерю пакетов без остановки всех потоков на одном TCP.

## Пример

Первый заход на сайт по HTTP/3: меньше round-trip на TLS+транспорт; при смене сети соединение может мигрировать.

## Примечание

UDP иногда режут корпоративные файрволы → fallback на HTTP/2. Для API за CDN обычно «просто работает», нюансы — у сетевой команды.
