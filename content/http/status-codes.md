---
title: HTTP status codes
summary: HTTP status codes — трёхзначные коды ответа: класс результата (2xx успех, 3xx редирект, 4xx ошибка клиента, 5xx ошибка сервера).
---

## Для чего

Чтобы клиент, прокси и мониторинг понимали исход запроса без разбора тела.

## Пример

`200 OK` — успех с телом.  
`201 Created` — ресурс создан.  
`204 No Content` — успех без тела.  
`401` — не аутентифицирован; `403` — нет прав.  
`500` — сбой сервера.

## Примечание

Не маскируйте ошибки под `200`. `401` ≠ `403`. Пустой успех чаще `204`, а не `200` с пустым телом.
