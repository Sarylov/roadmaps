---
title: HTTP/2 streams
summary: HTTP/2 stream — независимый двунаправленный поток кадров внутри одного соединения, со своим ID и flow control.
---

## Для чего

Чтобы мультиплексировать запросы и управлять приоритетом/окном каждого потока отдельно.

## Пример

Запрос картинки = stream #5, API-вызов = stream #7; они не ждут друг друга в одной очереди HTTP/1.1.

## Примечание

Не путать с Node.js Stream API — разные абстракции. На практике чаще пользуетесь HTTP-клиентом, а не кадрами вручную.
