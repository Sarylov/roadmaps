---
title: Filtering
summary: Filtering — сужение списка через query по заранее разрешённым полям и операторам (whitelist).
---

## Для чего

Чтобы клиент фильтровал выдачу без зоопарка эндпоинтов, а сервер безопасно строил WHERE только из allow-list.

## Пример

`GET /products?status=active&price_gte=100`  
Сервер мапит только известные ключи → SQL/ORM, остальное игнорирует или `400`.

## Примечание

Свободный filter-DSL без whitelist → SQL injection и тяжёлые запросы. Индексы должны покрывать частые фильтры.
