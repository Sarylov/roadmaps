---
title: API contracts
summary: API contract — зафиксированное описание интерфейса: пути, схемы, ошибки, примеры (часто OpenAPI).
---

## Для чего

Чтобы фронт, мобилки и другие сервисы могли интегрироваться без устных договорённостей и ловить дрейф в CI.

## Пример

OpenAPI: `POST /orders` + schema body/response.  
Из контракта генерят клиент/моки; contract-тесты падают, если сервер отклонился.

## Примечание

Breaking change без versioning ломает клиентов. Контракт — не замена runtime-валидации, а её источник правды.
