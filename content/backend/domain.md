## Для чего

Чтобы правила («нельзя отменить доставленный заказ») жили отдельно от HTTP и SQL и не дублировались.

## Пример

`Order.cancel()` бросает, если статус `SHIPPED`.  
Controller/service только вызывают; правило одно в домене.

## Примечание

Anemic domain — одни поля без поведения, логика в сервисах. Для простого CRUD часто ок; для сложного домена — риск расползания правил.
