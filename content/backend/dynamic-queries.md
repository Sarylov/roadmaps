---
title: Dynamic queries
summary: Dynamic queries — сборка WHERE/ORDER/JOIN в рантайме из фильтров пользователя, а не один захардкоженный SQL.
---

## Для чего

Чтобы поддержать поиск/фильтры API (`?status=&from=`) без комбинаторного взрыва готовых методов.

## Пример

Если передан `status` — добавить `eq(orders.status, status)`; если `q` — `ilike` по email. Пустые фильтры не попадают в WHERE.

## Примечание

Собирайте через API query builder / параметры (`$1`), никогда конкатенацией строк от клиента — SQL injection. Следите, чтобы динамика не убивала использование индексов.
