---
title: Server
summary: Server во Fastify — экземпляр приложения (`fastify()`), который принимает HTTP-запросы, держит плагины, хуки и маршруты.
---

## Для чего

Чтобы поднять HTTP API: слушать порт, зарегистрировать роуты и общую инфраструктуру (логгер, schema, плагины).

## Пример

```js
const app = Fastify();
app.get('/health', async () => ({ ok: true }));
await app.listen({ port: 3000 });
```

## Примечание

Один instance = один процесс. Масштаб — несколько процессов/инстансов за балансировщиком, не «ещё listen в том же процессе».
