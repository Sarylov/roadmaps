---
title: EXPLAIN ANALYZE
summary: EXPLAIN ANALYZE — выполняет запрос и показывает план с фактическими временем и числом строк.
---

## Для чего

Чтобы сравнить оценки планировщика с реальностью и найти место, где «ожидали 10 строк — получили миллион».

## Пример

```sql
EXPLAIN (ANALYZE, BUFFERS) SELECT ...;
```

## Примечание

На проде осторожно: реально гоняет запрос (и пишет, если это DML). Для чтения на копии / с лимитом риска.
