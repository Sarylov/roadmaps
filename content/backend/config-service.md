---
title: Config service
summary: Config service — централизованная/внешняя конфигурация для сервисов (не только локальный `.env` в образе).
---

## Для чего

Чтобы менять флаги и URL зависимостей без пересборки образа и держать конфиг согласованным по окружениям.

## Пример

Spring Cloud Config / Consul KV / K8s ConfigMap: сервис на старте (или watch) читает `feature.x=true`.

## Примечание

Секреты лучше не в том же plain config — отдельный secrets backend. Версионируйте и аудируйте изменения конфига.
