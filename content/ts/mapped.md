## Зачем нужно

Чтобы явно выразить и переиспользовать поведение, связанное с «mapped», а не держать его зашитым в одном месте.

## Как работает

mapped — это types: { [K in keyof T]: ... } трансформируют форму.

Частая ошибка: key remapping via as; -readonly/-? модификаторы.
