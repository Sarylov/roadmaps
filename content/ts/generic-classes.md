---
title: Generic Classes
summary: Generic class — класс с параметром типа `<T>`, который параметризует поля, конструктор и методы одним типом.
---

## Для чего

Чтобы один класс работал с разными типами данных без дублирования и с проверкой типов (коллекции, репозитории, кеши, очереди).

## Пример

```ts
class Box<T> {
  constructor(private value: T) {}
  get(): T {
    return this.value
  }
}

const n = new Box(42)        // Box<number>
const s = new Box('hi')      // Box<string>
```

## Примечание

Поля класса инвариантны: `Box<Dog>` не подставляется туда, где ждут `Box<Animal>`, даже если `Dog extends Animal`. Для методов с аргументами важна контравариантность параметров.

## Вопросы и ответы

### Чем generic class отличается от generic function?

У класса `T` фиксируется при создании экземпляра и общий для всех методов. У функции `T` выводится на каждый вызов отдельно.

### Нужны ли constraints на классе?

Да, если методы обращаются к полям `T`: `class Repo<T extends { id: string }>`. Без constraint TypeScript не знает shape.

### Когда generic class избыточен?

Если тип используется один раз в одном методе — достаточно generic-функции. Класс оправдан, когда состояние и API живут вокруг одного `T`.
