---
title: Intersections
summary: Intersection `A & B` — значение, которое одновременно удовлетворяет обоим типам.
---

## Для чего

Чтобы собрать тип из нескольких контрактов: базовые поля + опции, миксины props, пересечение ограничений.

## Пример

```ts
type WithId = { id: string };
type Named = { name: string };
type User = WithId & Named; // { id: string; name: string }
```

## Примечание

Пересечение примитивов вроде `string & number` даёт `never`. Для объектов `&` «склеивает» поля; конфликт несовместимых типов поля тоже ведёт к `never`.

## Вопросы и ответы

### Когда брать `&`, а когда `|`?

`&` — нужны оба набора свойств сразу. `|` — значение одно из альтернатив.

### Чем intersection отличается от extends у interface?

`interface C extends A, B` похож на `A & B` для объектов. `&` работает и с type aliases, union’ами и условными типами.

### Зачем intersection в React/API-типах?

Часто комбинируют базовый тип с опциями: `Props & { disabled?: boolean }` — не дублируя поля вручную.
