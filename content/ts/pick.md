---
title: Pick
summary: `Pick<T, K>` — utility type, который берёт из T только ключи K.
---

## Для чего

Чтобы сделать узкий тип из существующего (например DTO только с нужными полями) без копипасты.

## Пример

```ts
type User = { id: string; name: string; passwordHash: string }

type UserIdName = Pick<User, 'id' | 'name'>
// { id: string; name: string }
```

## Примечание

`K` должен быть `keyof T`. Иначе TypeScript выдаст ошибку.

## Вопросы и ответы

### Чем Pick отличается от Omit?

`Pick` оставляет перечисленные ключи. `Omit` удаляет перечисленные и оставляет остальные. Если нужных полей мало — чаще `Pick`; если выкинуть одно-два — `Omit`.

### Когда лучше вручную описать тип?

Когда набор полей — отдельный контракт API и не должен молча меняться при изменении `T`. `Pick` от entity связывает DTO с моделью: плюс для sync, минус для независимой эволюции.

### Можно ли Pick от union?

`Pick` ожидает объектный тип. Для union ключей обычно комбинируют с mapped/conditional types или сначала нормализуют тип.
