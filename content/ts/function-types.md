---
title: Function types
summary: Function type описывает сигнатуру функции — типы параметров и возвращаемого значения (`(a: number) => string`).
---

## Для чего

Чтобы типизировать колбэки, хендлеры и зависимости: что можно передать и что функция обязана вернуть.

## Пример

```ts
type Mapper = (n: number) => string;

const toStr: Mapper = (n) => String(n);
```

## Примечание

В strict-режиме параметры функций контравариантны, return — ковариантен: нельзя подставить функцию, которая «ждёт более узкий» аргумент. Бывают call и construct signatures (`new (...)`).

## Вопросы и ответы

### Чем отличается `(x: number) => void` от функции, которая реально что-то возвращает?

Для колбэков `void` значит «возвращаемое значение игнорируют». Функция может вернуть число — вызывающий его не использует.

### Что такое callable и construct signature?

Callable — вызов как функция `fn()`. Construct — через `new` (`new Foo()`). Один тип может описывать оба.

### Зачем тип функции, если есть вывод типов?

Для публичных API, DI и колбэков вывод с места вызова недостаточен: контракт задают заранее, чтобы сломать несовместимую реализацию на compile-time.
