## Зачем нужно

Частый KILLER-вопрос на собеседованиях. Переиспользуемые типизированные API и абстракции. Упор на систему типов, inference и дизайн публичного API.

## Как работает

**API design**: Дизайн generic API: defaults, constraints, понятные имена параметров.

Слишком умные типы ухудшают DX ошибок.

Публичный API типизируйте консервативнее внутренностей.

Документация: [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html).
