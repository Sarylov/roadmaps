---
title: Functional requirements
summary: Functional requirements — что система должна уметь делать для пользователя/бизнеса (фичи и сценарии).
---

## Для чего

Чтобы на system design сначала зафиксировать поведение, а не сразу рисовать Kafka.

## Пример

URL shortener: создать короткую ссылку, редирект по коду, опционально статистика кликов. Не функциональное — «миллион RPS».

## Примечание

Уточняйте акторов и edge cases (удаление, истечение). Без FR легко спроектировать не ту систему.
