---
title: Horizontal scaling
summary: Horizontal scaling (scale out) — добавить больше инстансов/нод за балансировщиком.
---

## Для чего

Чтобы расти сверх одной машины и переживать падение отдельных нод.

## Пример

10× stateless API pods за LB. Для БД — шарды/реплики, не «просто ещё один primary» без плана.

## Примечание

Требует stateless (или вынесенный state), идемпотентности и шардирования данных. Сложнее ops, выше потолок.
