## Зачем нужно

Тема регулярно встречается на backend-интервью: сильный ответ связывает механизм с наблюдаемым поведением, отказами и production-решением.

## Как работает

Load balancer отправляет запросы на несколько instances; autoscaler меняет их число по нагрузке. Session, файлы и locks выносят во внешние системы, а background jobs делают идемпотентными.

## Ответы

### Как работает Горизонтальное масштабирование на практике?

Load balancer отправляет запросы на несколько instances; autoscaler меняет их число по нагрузке. Session, файлы и locks выносят во внешние системы, а background jobs делают идемпотентными.

### Какой типичный failure mode связан с Горизонтальное масштабирование?

Локальная session и in-memory cache дают разные ответы после переключения instance. Scale-out переносит bottleneck в БД, создаёт retry storms и требует readiness, graceful drain и ограничения concurrency.

### Какие trade-offs важно назвать для Горизонтальное масштабирование?

Stateless HTTP tier обычно масштабируют горизонтально. Stateful database сначала усиливают/реплицируют, затем partition; цена scale-out — координация, наблюдаемость и более сложные отказы.
