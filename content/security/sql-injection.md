---
title: SQL injection
summary: SQL injection — подстановка враждебного SQL через пользовательский ввод, если запрос собирают конкатенацией строк.
---

## Для чего

Чтобы не отдать БД атакующему (чтение чужих строк, DROP, bypass login).

## Пример

Плохо: `"WHERE email = '" + email + "'"`.  
Хорошо: параметризованный запрос / ORM `$1` / `eq(users.email, email)`.

## Примечание

Экранирование руками хрупко. Raw SQL только с плейсхолдерами. WAF — доп. слой, не замена правильным запросам.
