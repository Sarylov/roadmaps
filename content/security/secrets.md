---
title: Secrets
summary: Secrets — чувствительные значения (ключи БД, JWT secret, API keys), которые нельзя светить в коде, логах и клиенте.
---

## Для чего

Чтобы компрометация репозитория или фронта не давала мгновенный доступ к инфраструктуре.

## Пример

`DATABASE_URL` и `JWT_SECRET` — из env / Vault / cloud secret manager, не из git. В логах — redaction.

## Примечание

Ротация, минимальные права, разные секреты на env. `.env` в `.gitignore`; сканеры утечек в CI.
