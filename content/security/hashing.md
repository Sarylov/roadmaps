title: Hashing
summary: Hashing — односторонняя функция: из данных получают фиксированный отпечаток, обратно восстановить исходник нельзя (в норме).
---

## Для чего

Чтобы проверять целостность и хранить секреты вроде паролей без возможности «расшифровать».

## Пример

`sha256(file)` — проверка, что файл не изменили.  
Пароль — `argon2`/`bcrypt`, не простой SHA.

## Примечание

Одинаковый вход → одинаковый hash (без соли). Для паролей обязательны медленный kdf + salt. Hash не заменяет encryption для данных, которые надо читать обратно.
