---
title: Input validation
summary: Input validation — проверка и ограничение входных данных на границе системы до бизнес-логики и БД.
---

## Для чего

Чтобы отсечь мусор, неожиданные типы и часть атак раньше, чем они дойдут до ядра.

## Пример

Схема: email формат, `quantity` — int 1…100, неизвестные поля — strip/reject → иначе `400`.

## Примечание

Валидация ≠ авторизация и ≠ полная защита от injection (нужны ещё параметризованные запросы). Дублируйте критичные проверки на сервере всегда.
