---
title: Path traversal
summary: Path traversal — доступ к файлам вне разрешённой директории через `../` в пользовательском пути.
---

## Для чего

Чтобы `GET /files?name=../../.env` не отдал секреты с диска.

## Пример

Плохо: `fs.readFile('/uploads/' + name)`.  
Хорошо: resolve + проверка, что итоговый path строго внутри base dir; лучше id файла из БД, не сырой path.

## Примечание

Нормализуйте путь (`path.resolve`) и сравнивайте префикс. Архивы тоже бывают с `../` внутри.
