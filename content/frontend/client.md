## Зачем нужно

Чтобы явно выразить и переиспользовать поведение, связанное с «client», а не держать его зашитым в одном месте.

## Как работает

client — это aPI client инкапсулирует HTTP, ошибки, auth headers.

Частая ошибка: размазанный fetch по компонентам — боль.

## Ответы

### Что такое client простыми словами?

client — это aPI client инкапсулирует HTTP, ошибки, auth headers.

### Зачем в коде нужен client?

Чтобы явно выразить и переиспользовать поведение, связанное с «client», а не держать его зашитым в одном месте.
