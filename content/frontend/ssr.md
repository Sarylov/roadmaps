---
title: SSR
summary: SSR (Server-Side Rendering) — HTML страницы генерируется на сервере на каждый запрос, затем гидратация на клиенте.
---

## Для чего

Чтобы быстрее показать контент и лучше SEO/шаринг, сохранив интерактивность React.

## Пример

Запрос → Node/Edge рендерит React в HTML → браузер рисует → JS гидратит обработчики.

## Примечание

Нужен сервер. Данные на сервере не должны «утекать» секретами в HTML. Следите за hydration mismatch.
