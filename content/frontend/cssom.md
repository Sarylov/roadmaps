---
title: CSSOM
summary: CSSOM — объектная модель стилей: CSS после парсинга, из которой браузер знает правила для узлов.
---

## Для чего

Чтобы видеть, почему CSS блокирует первый render и как стили участвуют в render tree.

## Пример

Пока грузится блокирующий CSS, render часто ждёт CSSOM. `getComputedStyle` читает уже посчитанные стили (может форсировать layout).

## Примечание

Инлайн и `<style>` тоже в CSSOM. Критический CSS / defer некритичного ускоряет FCP.
