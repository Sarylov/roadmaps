---
title: Slices
summary: Slice в FSD — вертикальный кусок предметной области внутри слоя (`features/cart`, `entities/product`) со своими сегментами.
---

## Для чего

Чтобы код одной фичи/сущности лежал рядом: UI, model, api — а не размазан по глобальным папкам.

## Пример

`features/add-to-cart/` → `ui/`, `model/`, `api/`, `index.ts` (public API).  
Страница собирает виджеты и фичи, не лезет во внутренности слайса.

## Примечание

Сегменты (`ui`, `model`, `lib`) — внутри слайса. Между слайсами одного слоя — через public API или подъём в entities/shared.
