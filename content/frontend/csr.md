---
title: CSR
summary: CSR (Client-Side Rendering) — сервер отдаёт оболочку/JS, UI строится в браузере после загрузки бандла.
---

## Для чего

Чтобы делать богатые SPA с быстрыми переходами после старта (админки, приложения за логином).

## Пример

Vite SPA: `index.html` + `main.tsx` → React монтируется в `#root`, данные — с API с клиента.

## Примечание

Хуже TTFB/SEO для публичного контента без доп. мер. Первый экран ждёт JS.
