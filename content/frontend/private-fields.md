---
title: Private fields
summary: Private fields (`#x`) — поля/методы класса, недоступные снаружи экземпляра и из наследников «напрямую».
---

## Для чего

Чтобы инкапсулировать внутренности без слабого соглашения `_private`.

## Пример

```js
class Bag {
  #items = []
  add(x) { this.#items.push(x) }
}
```

## Примечание

Обращение к `#x` вне класса — SyntaxError. Не то же самое, что WeakMap-паттерн приватности до появления синтаксиса.
