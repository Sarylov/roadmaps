---
title: Offload
summary: Offload — вынос тяжёлой работы с main thread в Worker/Wasm, чтобы сохранить отзывчивость UI (INP/FPS).
---

## Для чего

Чтобы поиск по большому массиву, парсинг CSV, крипто/сжатие не блокировали клики и ввод.

## Пример

Импорт Excel → Worker парсит → main только рисует таблицу. UI остаётся кликабельным.

## Примечание

Оверхед сообщений: мелкие задачи быстрее на main. Профилируйте до переноса.
