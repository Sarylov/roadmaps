## Зачем нужно

Чтобы явно выразить и переиспользовать поведение, связанное с «public API», а не держать его зашитым в одном месте.

## Как работает

Public API модуля — это единственная точка импорта.

Частая ошибка: deep import ломает инкапсуляцию.

## Что спрашивают

- Что такое public API простыми словами?
- Зачем в коде нужен public API?
- Какие ошибки и ограничения связаны с public API?

## Ответы

### Что такое public API простыми словами?

Public API модуля — это единственная точка импорта.

### Зачем в коде нужен public API?

Чтобы явно выразить и переиспользовать поведение, связанное с «public API», а не держать его зашитым в одном месте.

### Какие ошибки и ограничения связаны с public API?

Deep import ломает инкапсуляцию. Имеет смысл сравнить с ближайшей альтернативой и понять, когда механизм избыточен.
