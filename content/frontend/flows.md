## Для чего

Чтобы ловить поломки на стыке UI, роутинга и API, которые unit не видит.

## Пример

Login → открыть каталог → add to cart → checkout → увидеть confirmation.  
Селекторы — role/text, не хрупкий CSS.

## Примечание

Мало, но критичных flows. Стабильный test env + изоляция данных; иначе flaky.
