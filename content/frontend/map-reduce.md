---
title: map / reduce
summary: map создаёт новый массив из элементов; reduce сворачивает массив к одному значению (сумма, объект, пайплайн).
---

## Для чего

Чтобы трансформировать и агрегировать данные без ручных циклов с мутацией.

## Пример

`users.map(u => u.id)`  
`nums.reduce((sum, n) => sum + n, 0)`  
`filter + map` часто читаемее одного сложного reduce.

## Примечание

map не мутирует исходный массив (если колбэк сам не мутирует объекты). Пустой reduce без initial — ошибка.
