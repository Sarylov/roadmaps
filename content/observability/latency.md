---
title: Latency
summary: Latency — время ответа операции (обычно p50/p95/p99), не только среднее.
---

## Для чего

Чтобы видеть медленность так, как её чувствует хвост пользователей, а не «средняя температура по больнице».

## Пример

API `p95 = 800ms` при среднем 50ms — у 5% боль. Смотрите гистограммы/перцентили в Prometheus/APM.

## Примечание

Среднее скрывает выбросы. Разделяйте latency по эндпоинту и зависимости (БД, HTTP).
