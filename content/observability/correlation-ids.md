---
title: Correlation IDs
summary: Correlation / request ID — единый идентификатор, который проходит по логам и сервисам одного запроса/сценария.
---

## Для чего

Чтобы собрать цепочку «что случилось с этим запросом» из кучи сервисов и строк логов.

## Пример

Gateway ставит `X-Request-Id` → API и worker пишут его в каждый log → в UI поиска один id = весь путь.

## Примечание

Генерируйте, если нет входящего; прокидывайте дальше. В трейсинге ту же роль играют `traceId`/`spanId`.
